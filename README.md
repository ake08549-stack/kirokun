# 有料の文字起こしサービスを、自分のパソコンで無料にする手順 ― 「きろくん」

録音や動画の文字起こしは、月額サービスを契約しなくても、自分のパソコンの中だけでできます。
この手順書では、その仕組み「きろくん」を自分のパソコンで動かす方法を紹介します。中身はClaude(AI)と一緒に作りました。

> きろくんは個人が作った無料のツールです。Notta など既存のサービスとは関係ありません。

---

## できること

| | 一般的な有料サービスの無料プラン | きろくん |
|---|---|---|
| 1回の長さ | 数分まで、など制限あり | **制限なし** |
| 月の利用時間 | 月◯分まで | **制限なし** |
| 書き出し(TXT / 字幕ファイル) | 有料プランのみのことが多い | **無料**(TXT / SRT / VTT) |
| 音声の行き先 | 会社のサーバーへアップロード | **パソコンの外に出ない** |
| 要約 | 回数制限あり | **ボタン1つでClaudeに渡して議事録化** |
| 会議への自動参加ボット | あり | なし(録音ファイルを読み込んで使います) |

**精度の目安**: 41秒の会議の読み上げ音声で試したところ、数字の書き方の違いを除いて誤りゼロでした(2026年11月、Mac で計測)。実際の会議の声だと、雑音や話し方によって誤りは増えます。

---

## 必要なもの

- **パソコン**: Mac または Windows(メモリ8GB以上がおすすめ)
- **ブラウザ**: Google Chrome または Microsoft Edge(最新版)
- **空き容量**: 約2GB(初回にAIモデルを約0.7GBダウンロードします)
- **Node.js**: 無料のソフト。下の手順1で入れます
- **Claude Code**(手順Bの場合のみ)

## 手順A: 完成版をそのまま動かす(15分)

### 1. Node.js を入れる(初回だけ)
1. https://nodejs.org/ja を開く
2. 「LTS」と書かれた方をダウンロードしてインストール(全部「次へ」でOK)

### 2. きろくんのフォルダをダウンロードする
1. このページ(https://github.com/ake08549-stack/kirokun)の上にある緑の **「Code」** ボタン → **「Download ZIP」**
2. ダウンロードしたZIPを開き、出てきた `kirokun-main` フォルダを **デスクトップ** に置く

### 3. 起動する
**Mac**: 「ターミナル」を開いて、次を1行ずつ貼り付けて Enter
```bash
cd ~/Desktop/kirokun-main
```
```bash
npm install
```
```bash
npm start
```

**Windows**: デスクトップの `kirokun-main` フォルダを開き、アドレス欄に `cmd` と入力して Enter。黒い画面で `npm install` → `npm start` の順に実行。

ブラウザが自動で開き、きろくんの画面が出れば成功です。開かなければ、Chrome で http://localhost:4173 を開いてください。

### 4. 使う
画面は左(履歴)・中央(文字起こし)・右(書き出しと要約)の3つに分かれています。
1. 中央に音声・動画ファイルをドロップ(またはマイクで録音)
2. 「文字起こしを開始」を押す。初回だけモデルのダウンロードに数分かかります
3. 結果の文章はその場で直せます。左に出る時刻(`[00:35]` など)を押すと、その位置から再生します。画面下の再生バーで、再生・一時停止・位置の移動・再生速度の変更ができます(キーボードは Space で再生/停止、← → で5秒移動)
4. 右の「書き出し」から TXT / SRT / VTT で保存、または全文コピー
5. 右の「Claudeで要約」を押すと、文字起こしがコピーされ Claude が開きます。貼り付けて送れば議事録になります。返ってきた要約は、同じ画面の貼り付け欄に入れておくと、履歴に保存されて後から見直せます
6. 過去の結果は左の履歴から開けます(音声は保存しないので、履歴から開くと再生はできません)

### 2回目からは
`cd ~/Desktop/kirokun-main` → `npm start` だけで起動します。モデルは保存済みなので、すぐ使えます。
終わるときは、黒い画面で `Ctrl + C` を押すか、画面を閉じます。

## よくある質問

**Q. 本当に音声は外に出ないの?**
A. 文字起こしの処理は、すべてあなたのブラウザの中で行います。通信するのは、初回にAIモデル(OpenAIが公開している Whisper)を Hugging Face から取ってくるときだけです。「Claudeで要約」は、押したときにあなたが自分で貼り付けるまで、どこにも送りません。

**Q. 遅い・「軽量モード」と出る**
A. パソコンがWebGPUに対応していないと、軽いモデルに自動で切り替わります。精度は下がります。Chrome を最新版にすると改善することがあります。

**Q. iPhone / Android で使える?**
A. 今は想定していません。パソコンで使ってください。

**Q. 商用で使っていい?**
A. 使っているモデルとライブラリは、商用利用できるライセンス(MIT / Apache-2.0)です。
